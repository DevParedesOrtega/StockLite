# StockLite

StockLite es una aplicación web de control de inventario diseñada para facilitar la administración de productos y el seguimiento de sus existencias.

El sistema permite registrar, consultar, editar y desactivar productos, controlar niveles mínimos y máximos, gestionar entradas y salidas de mercancía y consultar el historial de movimientos mediante un Kardex.

### Funcionalidades principales

- Gestión de productos.
- Registro de entradas y salidas de inventario.
- Control de existencias máximas y mínimas.
- Kardex con historial de movimientos.
- Cálculo de costos mediante promedio ponderado móvil.
- Consulta de reportes y estadísticas.
- Filtros por producto, fechas y tipo de movimiento.
- Exportación de movimientos en formato CSV.
- Almacenamiento de información mediante LocalStorage.

### Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

### Estado del proyecto

Primera versión funcional. La información se almacena localmente en el navegador, por lo que todavía no cuenta con una base de datos centralizada ni sincronización entre dispositivos.
